# BPL Dream 11 

Live Demo: [https://bpl-dream-11-draft-tiger.netlify.app/](https://bpl-dream-11-draft-tiger.netlify.app/)  
GitHub: [https://github.com/AritraApon/BPL-Dream-11](https://github.com/AritraApon/BPL-Dream-11)  

A web application to create and manage your own BPL Dream 11 fantasy cricket team. Users can select players, manage squads, and simulate fantasy cricket drafts in an interactive and user-friendly interface.



## Features
- User-friendly interface for creating a fantasy cricket team
- Add, remove, and manage players
- Interactive draft selection
- Responsive design for mobile and desktop
- Real-time team overview

## Technologies Used
- React.js
- JavaScript
- HTML & Tailwind 
- Netlify for deployment
